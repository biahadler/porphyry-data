# porphyry-data

The series of notebooks provided in this repository assists with extracting data from the global Landscape evolution models provided in the HydroShare repository http://www.hydroshare.org/resource/0106c156507c4861b4cfd404022f9580 (Salles, T., L. Husson, M. Lorcery, B. H. Boggiani (2022). Paleo-Physiography Project). 

Datasets related to some of the mines studied in this project can be access at [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.11239057.svg)](https://doi.org/10.5281/zenodo.11239057). 

Datasets from elevation and climate are referenced in the notebooks 2_plotElevationTime_perMine and 3_Climate_Comparison.
